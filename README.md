 🌐 GovTechCRM – Citizen Complaint Management System

 🔎 Project Scope
GovTechCRM is a government technology CRM system designed to streamline **citizen complaint management**.  
It ensures transparency, multilingual accessibility, and efficient resolution through dashboards and analytics.

 🎯 Objectives
- Provide a platform for citizens to **submit and track complaints**.
- Enable administrators to **monitor SLA compliance**.
- Integrate **AI sentiment analysis** for better insights.
- Offer **multilingual support** for inclusivity.
- Map complaints geographically for **public transparency**.

 🚀 Features
- 👥 Role-based access (Citizen, Admin)
- 📝 Complaint submission & tracking
- ⏱ SLA monitoring
- 🤖 AI-powered sentiment analysis
- 🌍 Multilingual support
- 📊 Analytics dashboard & public complaint mapping

 🛠️ Tech Stack
- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, JavaScript (React/Angular optional)
- **Database:** SQLite / MySQL
- **Other Tools:** Git, GitHub, Power BI
